# Simple Monitoring and Tracking Website Scope

The final product is a **browser website only**. It presents one simple operations page with the worker’s last known location, current band status, three essential health readings, three atmosphere readings, a source-linked **Reading / Standard / Status** table, and a controlled gas-alarm test.

The page deliberately excludes mobile-app navigation, APK-specific user flows, additional product panels, and hardware-architecture detail. The C++ and Python reference code remains available in the repository, but the website interface focuses on one task: monitoring a mine worker’s current safety status.
