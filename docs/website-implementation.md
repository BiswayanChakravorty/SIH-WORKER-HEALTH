# Responsive Website Implementation Brief

The project’s web build will now present a responsive operations dashboard. Desktop displays a left rail, header, monitoring cards, a standards table, and the alarm test workflow. Narrow screens collapse the rail and reorganize the cards for vertical scanning without removing critical warning information.

The page will preserve the previously verified physiological and atmospheric safety standards, with each visible operational metric including current **Reading**, applied **Standard**, and calculated **Status**. Interactions are limited to a safe controlled demo: a user can trigger, acknowledge, and reset a simulated gas-alarm state. The user interface will never treat acknowledgement as hazard resolution.
